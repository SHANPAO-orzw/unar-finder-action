# unar-finder-action

在 macOS 访达里右键解压 RAR、ZIP 等压缩包，无需每次打开终端。

这是一个调用 Homebrew `unar` 的 Automator 快速操作，包含密码弹窗和安装脚本。

## 功能

- 在访达选择文件，右键 → **快速操作 → 解压到当前文件夹**。
- 支持同时选择多个压缩包。
- 遇到加密压缩包时弹窗输入密码，输入内容隐藏；最多尝试 3 次，支持取消。
- 先在原位置的临时文件夹中解压，成功后才保存结果。输错密码、取消和解压失败会清理临时文件夹。
- 已有同名解压文件夹时自动加编号，不覆盖已有内容。主动重复解压仍会保留多份结果。

## 环境

- macOS，访达和系统自带的 Automator（自动操作）。
- 当前版本使用 Apple Silicon 的 Homebrew 默认路径 `/opt/homebrew/bin/unar` 和 `/opt/homebrew/bin/lsar`。
- 安装依赖只需执行一次：

```sh
brew install unar
```

Intel Mac 的 Homebrew 路径通常不同，需要相应修改源码和工作流中的工具路径。项目不包含 `unar` 本体。

## 安装

**推荐：** 点击仓库上方 **Code → Download ZIP**，解压后双击 `install.command`。

安装脚本会把已存在的“解压到当前文件夹.workflow”和“解压到当前文件夹 2.workflow”移到备份位置，再安装一个最新入口，不会处理其他快速操作。

备份位置：`~/Library/Application Support/unar快速操作备份/`。

也可以下载 [工作流安装包](dist/unar-finder-action.zip)，解压后双击其中的 `.workflow` 文件进行安装。更新已有版本时推荐使用 `install.command`，避免出现重复菜单。

首次运行时如系统询问是否允许访问访达或文件所在位置，请按需允许。若菜单未更新，重新打开访达窗口后再试。

## 使用

1. 在访达选中一个或多个压缩包。
2. 右键 → **快速操作 → 解压到当前文件夹**（部分系统也可能显示在“服务”菜单）。
3. 如果弹出密码窗口，输入压缩包密码；点“取消”会跳过当前压缩包。
4. 成功后，解压结果出现在压缩包旁边的独立文件夹中。

解压期间需要原位置的写入权限和足够磁盘空间。临时解压和最终保存可能同时占用空间。

密码不写入文件、不保存到钥匙串，也不会上传；调用 `unar` 时通过其 `-p` 参数传入，因此运行期间可能出现在本机进程参数中。

## 卸载

在访达选择 **前往 → 前往文件夹**，输入 `~/Library/Services/`，移除 `解压到当前文件夹.workflow` 即可。不会删除 Homebrew 的 `unar` 或已经解压的文件。

## 项目文件

- `src/extract.sh`：解压、密码输入、重试与清理逻辑。
- `解压到当前文件夹.workflow/`：可直接安装的访达快速操作，内嵌相同脚本。
- `install.command`：可双击运行的独立安装器，内嵌工作流。
- `dist/unar-finder-action.zip`：工作流安装包。

## 已验证

在本机使用加密 RAR、加密 ZIP 和普通 ZIP 验证了：正确密码解压、错误密码后重试、取消、连续三次密码错误、失败后临时目录清理，以及已有同名文件夹的保留。密码弹窗已由用户实际试用。
